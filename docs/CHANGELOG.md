# 变更日志

> 书写规则：
>
> 1. 标签仅限四类：`[Added]` 新增 / `[Fixed]` 修复 / `[Changed]` 优化 / `[Removed]` 移除。
> 2. 只记结果，不记过程：聚焦「做了什么」，不写实现原理、踩坑过程或代码细节。
> 3. 以功能视角总结，合并同类操作，避免重复记录。
> 4. 排序：日期分组从新到旧，同日条目从新到旧。
> 5. 涉及架构变更或深度技术选型时，同步更新 How2Build 下对应技术文档，并在条目末尾用 📝 标记指向文档标题。
> 6. 从功能角度出发，不书写技术细节。

## [2026-09-27]

- [Fixed] **[移动端]** 修复了手机浏览器工具栏遮住底部内容的问题：改为按实际可视高度布局，并适配底部安全区（带 home indicator 的机型）。
- [Fixed] **[移动端]** 修复了窄屏下设置项文字被挤成竖排的问题（改为上下排列），两列表单在窄屏下也改为单列。
- [Changed] **[移动端]** 优化了手机端浏览体验：侧边栏改为可开合的抽屉、正文占满全屏、问答侧栏在窄屏下占满宽度，并隐藏触摸屏上无意义的拖拽调宽与悬浮提示；在窄屏下自动展开侧边栏，避免只显示图标。
- [Changed] **[API 设置]** 优化了模型选择：改为正式下拉框并保留「手动输入」入口，避免候选被浏览器按输入值过滤、看起来只有一个模型。
- [Fixed] **[问答]** 修复了问答侧边栏的模型选项写死为某一厂商模型的问题，现随所配置的厂商动态变化，默认沿用设置中配置的模型。
- [Changed] **[API 设置]** 更正了 DeepSeek 的默认模型名——原名称并非实际可用模型，已改为接口真实返回的名称。
- [Added] **[API 设置]** 新增了多厂商支持：内置 DeepSeek / OpenAI / Anthropic(Claude) / Kimi / 通义千问 / 智谱 GLM / Gemini 及「自定义」，并支持 OpenAI 兼容与 Anthropic 两种调用协议，切换厂商时自动匹配协议与默认地址。
- [Added] **[API 设置]** 新增了「获取模型列表」：可从所选厂商的接口拉取真实可用模型，也可直接手动输入模型名（不再受预设列表限制）。
- [Changed] **[论文分析]** 优化了分析失败时的表现：不再显示「Demo 降级输出」等占位文案，改为留空并明确提示真实失败原因，避免把失败伪装成分析结果。
- [Added] **[论文详情]** 新增了未配置大模型 API Key 时的提示：TLDR 与八维分析无法生成时给出说明，并可一键跳转到 API 设置补充配置。
- [Added] **[部署]** 新增了 Docker 镜像与云端部署配置，可部署到 Railway 等平台；运行时数据目录支持指向持久化卷，避免重启后数据丢失。
- [Changed] **[开发流程]** 统一了临时开发脚本的存放位置：集中到专用目录并加入忽略规则，不再散落各处，需要清理时直接删除该目录即可。
- [Added] **[初始数据]** 新增了内置初始文献：首次启动时自动写入三篇大模型相关论文（Transformer / BERT / GPT-3），随仓库附带 PDF 原件，并像「刚上传 PDF」一样自动完成解析与分析（含 TLDR 与八维分析）；仅在文献库为空时写入一次。
- [Fixed] **[文献导入]** 修复了导入的文献（仅有题录、没有 PDF）会一直停留在「正在分析」的问题；同时「重新分析」在缺少 PDF 时会明确提示先上传原件。
- [Fixed] **[问答]** 修复了网络中断重试时会重复输出已生成内容的问题。
- [Fixed] **[问答]** 修复了修改论文信息后，问答上下文可能从全文降级为摘要的问题。
- [Fixed] **[问答]** 修复了新建会话时论文不存在会报服务器错误的问题。
- [Fixed] **[论文分析]** 修复了同一篇论文被重复触发分析时状态互相覆盖的问题。
- [Fixed] **[论文阅读]** 修复了反复分析 PDF 时文件句柄未释放的问题。
- [Changed] **[搜索]** 优化了模糊搜索性能，大文本下不再卡顿。
- [Changed] **[备份与恢复]** 优化了数据库读写方式，并确保备份时数据已完整落盘。
- [Changed] **[标签 / 批注]** 优化了保存逻辑，避免并发操作产生重复数据。
- [Changed] **[论文阅读]** 优化了侧栏拖拽，消除拖动时的卡顿。
- [Changed] **[侧边栏]** 优化了论文列表刷新，数据未变化时不再重复渲染。
- [Changed] **[前端]** 统一了多处重复的工具函数。
- [Fixed] **[论文列表]** 修复了论文分析完成后标题被清空的问题。
- [Fixed] **[问答]** 修复了编辑消息后仍发送修改前内容的问题。
- [Fixed] **[搜索]** 修复了搜索结果排序会打乱主列表顺序的问题。
- [Fixed] **[论文详情]** 修复了打开 PDF 时新窗口出现 404 的问题。
- [Fixed] **[论文详情]** 修复了上传翻译件会把已完成论文的状态回退的问题。
- [Changed] **[侧边栏]** 优化了时钟刷新方式，消除了每秒重绘带来的卡顿。
- [Changed] **[网络请求]** 优化了请求处理：新增超时提示与更清晰的错误信息，并避免慢响应覆盖新结果。
- [Changed] **[导入 / 导出]** 优化了大文件的上传与批量导入处理，不再占用大量内存。
- [Changed] **[备份与恢复]** 优化了大文件备份与恢复的处理，不再占用大量内存。
- [Changed] **[问答]** 优化了耗时操作的处理方式，避免阻塞其他请求。
- [Changed] **[文献互通]** 优化了导入导出的兼容性：导出的引用键统一为 ASCII（兼容经典 LaTeX 引擎），RIS 不再重复输出年份，导入中文文献时不再把中文标题误写入英文字段。
- [Added] **[文献互通]** 新增了与 Zotero、Mendeley、EndNote、JabRef 等文献管理工具互相导入导出的功能，支持 CSL JSON、BibTeX、RIS 三种通用格式，导入时可自动识别格式并按 DOI / 标题去重。
- [Added] **[设置]** 新增了「导入 / 导出」设置页，可上传题录文件批量导入（含逐条结果反馈），并选择格式一键导出文献库。
- [Added] **[测试]** 新增了后端自动化测试，覆盖文献格式转换、导入导出流程与已修复的缺陷。
- [Fixed] **[论文编辑]** 修复了为尚无元数据的论文填写元数据时报错、无法保存的问题。
- [Changed] **[仓库配置]** 优化了运行时数据目录的忽略规则，避免本地密钥、数据库与日志被误提交。
- [Fixed] **[数据清理]** 修复了清空本地数据时报错、无法执行的问题。
- [Fixed] **[论文详情]** 修复了更新不存在的论文时返回服务器错误的问题。
- [Fixed] **[文件夹]** 修复了批量导入论文时全部失败、无法导入的问题。
- [Fixed] **[本地安全]** 修复了工作区文件可被外部直接下载、导致 API 密钥与论文数据库泄露的问题。
